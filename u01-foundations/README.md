# Unit 1: Linear algebra, gradients, probability, Bayes, hypothesis tests

Programs for Unit 1 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `gradients.py` | derivatives, partial derivatives and the gradient |
| `probability_bayes.py` | probability, Bayes' theorem and a hypothesis test |
| `vectors_matrices.py` | vectors and matrices with NumPy |

Run a program from this folder, e.g. `python gradients.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u01`.
