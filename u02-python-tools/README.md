# Unit 2: NumPy, Pandas, Matplotlib, Seaborn

Programs for Unit 2 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `numpy_basics.py` | NumPy arrays, vectorised arithmetic, broadcasting, indexing |
| `pandas_basics.py` | Pandas DataFrames: load, inspect, select, filter, group |
| `plotting.py` | plots with Matplotlib and Seaborn (saved to figures/) |

Run a program from this folder, e.g. `python numpy_basics.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u02`.
