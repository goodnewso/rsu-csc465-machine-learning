# Unit 3: Missing values, outliers, scaling, encoding, splitting, correlation

Programs for Unit 3 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `eda_correlation.py` | exploratory data analysis and correlation |
| `missing_values.py` | finding and handling missing values |
| `outliers.py` | detecting outliers with the IQR rule and z-scores |
| `scaling_encoding.py` | feature scaling and encoding categorical data |
| `splitting.py` | train-validation-test split, and scaling without leakage |

Run a program from this folder, e.g. `python eda_correlation.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u03`.
