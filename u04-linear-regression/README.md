# Unit 4: Simple and multiple linear regression, gradient descent

Programs for Unit 4 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `gradient_descent.py` | fitting linear regression by batch gradient descent |
| `multiple_linear.py` | multiple linear regression with a train-test split |
| `simple_linear.py` | simple linear regression by formula and with scikit-learn |

Run a program from this folder, e.g. `python gradient_descent.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u04`.
