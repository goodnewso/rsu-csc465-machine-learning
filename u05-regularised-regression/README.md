# Unit 5: Polynomial regression, Ridge, Lasso

Programs for Unit 5 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `polynomial.py` | polynomial regression, underfitting and overfitting |
| `ridge_lasso.py` | Ridge (L2) and Lasso (L1) regularisation |

Run a program from this folder, e.g. `python polynomial.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u05`.
