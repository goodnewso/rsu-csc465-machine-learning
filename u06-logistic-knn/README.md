# Unit 6: Logistic regression, k-nearest neighbours

Programs for Unit 6 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `knn.py` | k-nearest neighbours: classifying penguins by species |
| `logistic.py` | logistic regression: who is likely to have diabetes? |

Run a program from this folder, e.g. `python knn.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u06`.
