# Unit 7: Support vector machines, Naive Bayes spam filter

Programs for Unit 7 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `naive_bayes_spam.py` | a Naive Bayes spam filter for SMS messages |
| `svm.py` | support vector machines on the breast cancer data |

Run a program from this folder, e.g. `python naive_bayes_spam.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u07`.
