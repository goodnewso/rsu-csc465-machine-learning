# Unit 8: Decision trees, random forests, bagging, boosting, XGBoost

Programs for Unit 8 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `boosting.py` | boosting: AdaBoost, gradient boosting, XGBoost (diabetes) |
| `decision_tree.py` | a decision tree for penguin species, and impurity by hand |
| `random_forest.py` | one tree versus bagging versus a random forest (diabetes data) |

Run a program from this folder, e.g. `python boosting.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u08`.
