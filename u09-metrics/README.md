# Unit 9: MSE, RMSE, R², confusion matrix, precision, recall, F1, ROC-AUC

Programs for Unit 9 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `classification_metrics.py` | the confusion matrix, precision, recall, F1 and ROC-AUC |
| `regression_metrics.py` | MAE, MSE, RMSE and R^2, by hand and with scikit-learn |

Run a program from this folder, e.g. `python classification_metrics.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u09`.
