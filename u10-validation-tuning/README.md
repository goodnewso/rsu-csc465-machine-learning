# Unit 10: Bias and variance, k-fold cross-validation, grid and random search

Programs for Unit 10 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `bias_variance.py` | underfitting and overfitting seen in a validation curve |
| `cross_validation.py` | why one train-test split is not enough; k-fold CV |
| `tuning.py` | grid search and random search for hyperparameters (SVM) |

Run a program from this folder, e.g. `python bias_variance.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u10`.
