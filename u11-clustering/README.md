# Unit 11: k-means, hierarchical clustering, DBSCAN

Programs for Unit 11 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `dbscan.py` | DBSCAN finds clusters of any shape, and marks noise |
| `hierarchical.py` | agglomerative (hierarchical) clustering and a dendrogram |
| `kmeans.py` | k-means clustering of penguins, choosing k |

Run a program from this folder, e.g. `python dbscan.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u11`.
