# Unit 12: Principal component analysis, anomaly detection

Programs for Unit 12 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `anomaly.py` | anomaly detection on mobile-money transfers |
| `pca.py` | principal component analysis on the breast cancer data |

Run a program from this folder, e.g. `python anomaly.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u12`.
