# Unit 13: Content-based and collaborative filtering, matrix factorisation

Programs for Unit 13 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `collaborative.py` | user-based collaborative filtering on a small ratings table |
| `content_based.py` | content-based recommendation of courses |
| `movielens_mf.py` | matrix factorisation on MovieLens (100,000 ratings) |

Run a program from this folder, e.g. `python collaborative.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u13`.
