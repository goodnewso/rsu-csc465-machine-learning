# Unit 14: Backpropagation, PyTorch tensors and autograd, an MLP

Programs for Unit 14 of the RSU-CSC 465 lecture note.

| Program | What it does |
|---|---|
| `backprop_numpy.py` | a 2-4-1 neural network learns XOR by backpropagation |
| `pytorch_basics.py` | PyTorch tensors and automatic differentiation (autograd) |
| `pytorch_mlp.py` | a multilayer perceptron in PyTorch for handwritten digits |

Run a program from this folder, e.g. `python backprop_numpy.py`.
Figures are saved in `figures/` here. Run them all from the top folder with
`python tests/run_all.py u14`.
